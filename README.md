# BOROVY Platform

A workforce platform for rotational-shift employees with a promo code system and application management tools.

## Project Overview

BOROVY is a platform designed for rotational-shift workers looking for verified job opportunities. The platform uses a promo code system to connect workers with managers and allows all parties to track the hiring and application process.

## User Roles

### Worker

Workers can:

- Browse available rotational-shift job opportunities
- Apply for vacancies
- Register using a manager’s promo code
- Track the status of submitted applications

### Manager

Managers can:

- Create and manage personal promo codes
- Invite and register workers through promo codes
- Track worker activity and application statistics
- Monitor the progress of workers throughout the hiring pipeline

### Administrator

Administrators have full access to the platform and can:

- Manage users, roles, and permissions
- Oversee vacancies, applications, and promo codes
- Monitor platform activity and system-level data
- Configure and maintain the overall platform

## Technology Stack

### Backend

- NestJS 10
- PostgreSQL
- Prisma ORM
- JWT-based authentication
- Nodemailer

### Frontend

- Next.js 15
- TypeScript
- React 19
- Tailwind CSS
